> 何时读我：启动白屏、页面跳转白屏、运行中随机白屏、列表滑动白屏。
> 不适用：纯 JS 崩溃或内存问题 → crash-apm.md / oom-memory.md。
> 必须先有：现象、复现路径、影响版本 / 机型、APM 伴随异常。
> 产出：按五层决策树定位根因 + 修复方向 + 防劣化措施。

### 专项一：白屏排查与治理体系

#### 1. 白屏问题分类体系

| 分类维度     | 类型      | 典型根因区域                         |
| -------- | ------- | ------------------------------ |
| **发生阶段** | 启动白屏    | 原生启动流程、RN 容器初始化、首屏 Bundle 加载 |
|          | 页面跳转白屏  | 路由、Bundle 按需加载、页面初始化、数据注入      |
|          | 运行中随机白屏 | 内存警告、JS 异常、渲染进程崩溃、主线程卡死        |
|          | 列表滑动白屏  | Cell 复用、图片加载、离屏渲染、GPU 降频       |
| **影响范围** | 全量用户    | 代码 Bug、资源缺失、配置错误               |
|          | 特定系统版本  | iOS 系统兼容、API 行为变更              |
|          | 特定机型    | 硬件差异、内存阈值差异、CPU/GPU 架构         |
|          | 特定业务页面  | 业务代码 Bug、特定数据触发                |

#### 2. 分层排查决策树（严格执行，禁止跳步）

白屏问题上报
↓
第 0 步：现象收敛
├─ 复现路径是否明确
├─ 影响版本、系统、机型范围
├─ 必现 / 概率 / 偶发
└─ APM 是否有伴随异常（崩溃、内存警告、卡顿）
↓
第 1 层：系统层排查
├─ 是否仅特定 iOS 版本出现
├─ 系统版本是否有渲染 / 沙盒 / 权限相关变更
├─ 是否处于锁定状态（首启数据保护）
├─ 是否 Jetsam 杀进程导致的启动白屏
└─ 系统日志中是否有相关报错
↓ 排除系统原因
第 2 层：原生基建层排查
├─ RootView 是否正常创建
├─ 容器 View 背景色是否被意外清空
├─ 主线程是否阻塞（RunLoop 卡顿 > 1s）
├─ 启动阶段文件读取是否失败（加密保护）
├─ 图片资源 / 配置文件是否加载失败
└─ 内存警告是否触发了视图卸载
↓ 排除原生原因
第 3 层：桥接层排查
├─ RCTHost / RCTReactNativeFactory（新架构）是否初始化成功
├─ Bundle 文件是否加载、解析成功
├─ 首屏数据注入是否成功、是否为空
├─ JS 线程是否存活、是否崩溃
├─ 原生调用 JS 的方法是否执行失败
└─ JSI / TurboModule 调用是否阻塞、JS 任务队列是否堆积
↓ 排除桥接原因
第 4 层：RN 框架层排查
├─ JS 全局异常是否被捕获、是否导致渲染中断
├─ Error Boundary 是否生效、兜底视图是否展示
├─ 路由是否匹配失败、渲染了空组件
├─ 状态机异常导致 render 返回 null
├─ 样式计算异常（高度为 0、透明、移出屏幕）
└─ FlatList 等列表组件数据源为空或异常
↓ 排除框架原因
第 5 层：业务层排查
├─ 接口请求失败 / 数据异常导致空渲染
├─ 业务条件判断错误导致展示空态
├─ 特定数据触发 JS 异常
└─ 业务组件 Bug
↓
定位根因 → 输出修复方案 → 验证 → 防劣化

#### 3. 各层级典型根因与修复方向

- **系统层**：iOS 升级后文件加密策略变更 → 关键数据移至无保护目录，延后非关键读取；后台唤醒渲染受限 → 退后台保存快照，前台恢复重渲染
- **原生层**：主线程阻塞渲染超时 → 耗时操作移至子线程；沙盒读取失败 → 增加兜底与降级页面；内存警告误删视图 → 优化资源释放逻辑
- **桥接层**：RN 容器（RCTHost / RCTReactNativeFactory）初始化失败 → 增加重试 + 原生降级页；Bundle 加载失败 → 版本回退 + 内置兜底包；数据注入时序错误 → 增加就绪信号同步
- **RN 框架层**：JS 异常中断渲染 → 全局+页面双层 Error Boundary；路由匹配失败 → 统一错误页兜底；样式异常不可见 → 关键容器增加最小高度与背景色校验

#### 4. 白屏防劣化体系

1. **检测层**：原生侧像素级白屏检测、JS 侧渲染成功率埋点
2. **兜底层**：三级兜底 —— JS Error Boundary → RN 根视图重建（bridgeless 下不再有 Bridge 重启）→ 原生降级页
3. **监控层**：白屏率纳入核心大盘，按页面、系统、机型维度下钻
4. **巡检层**：发版前自动化遍历核心页面，白屏自动截图报警
